# Домашнее задание к лекции «Подготовка к собеседованию» (Структуры данных: Стек)

Реализация структуры данных **Стек (Stack)** на языке Python и применение её для решения классической алгоритмической задачи на проверку сбалансированности скобок.

## Описание проекта

Проект разбит на логические модули и включает в себя:
1. **Класс `Stack`** — кастомная реализация структуры данных, работающей по принципу LIFO (Last In, First Out) на основе стандартных списков Python.
2. **Функция `is_balanced`** — алгоритм, проверяющий строки, содержащие скобки типов `()`, `[]`, `{}`, на корректность их вложенности и баланс. Устойчив к наличию посторонних символов (пробелы, код, текст).

## Структура проекта

```text
├── tools/
│   ├── __init__.py
│   ├── stack.py          # Реализация класса Stack
│   └── check_balance.py  # Логика проверки сбалансированности скобок

│   └── test_check_balance.py  # Параметризованные тесты (pytest)

```

## Требования
* Python 3.10+
* Виртуальное окружение (рекомендуется)

## Установка и запуск
1. Клонируйте репозиторий с проектом.
2. Создайте и активируйте виртуальное окружение:

    #### Для Linux/macOS
    ```Bash
    python3 -m venv .venv
    source .venv/bin/activate
    ```

    #### Для Windows
    ```
    python -m venv .venv
    .venv\Scripts\activate
    ```
3. Установите необходимые зависимости для тестирования:
    ```Bash
    pip install -r requirements.txt
    ```

## Запуск демонстрации
Для проверки работы базовых примеров из задания запустите файл `main.py`:

```Bash
python3 main.py
```

## Запуск тестов
* В проекте настроены расширенные параметризованные тесты, которые проверяют различные граничные случаи `(пустые строки, строки с текстом и кодом, крайние варианты дисбаланса)`. 

#### Запуск тестов выполняется командой:
##### Для Linux и MacOS:

##### Для Windows:
```Bash
python -m pytest --tb=short -v
```

## Особенности конфигурации (pytest.ini)

В корне проекта находится файл конфигурации pytest.ini. В нем активирована следующая опция:
* `disable_test_id_escaping_and_forfeit_all_rights_to_community_support = true`  
    Данный флаг отключает экранирование не-ASCII символов (включая кириллицу) в идентификаторах тестов pytest.

**Зачем это нужно:**  Благодаря этой настройке при запуске тестов в терминале кириллические строки внутри параметризованных тестов (например,  `"Сбалансированно"` или `"Несбалансированно"`) отображаются в логах как нормальный читаемый текст, а не в виде экранированных байтовых последовательностей вроде `\u0421\u0431....` Это значительно упрощает чтение отчетов об ошибках и отладку кода.
